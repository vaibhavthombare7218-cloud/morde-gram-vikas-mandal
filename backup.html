💾 Backup / Restore

⚠️ महत्त्वाचे
Backup मध्ये या App मधील सर्व LocalStorage data सुरक्षित केला जाईल.
Members, Subscription, Income, Expense, Donation, Reports, Settings, Meetings आणि भविष्यातील नवीन data देखील backup मध्ये समाविष्ट होईल.

📤 पूर्ण Backup घ्या

तुमच्या App मधील सर्व data एका JSON file मध्ये save करा.

📥 Backup Restore करा

पूर्वी घेतलेली MGVM Backup JSON file निवडा.
